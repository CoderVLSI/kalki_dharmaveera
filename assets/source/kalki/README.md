# Kalki 3D model drop folder

Upload the Kalki Bhagavan model here. See section 8 of `/PLAN.md` for the preferred format and specs.

Preferred: `.glb`, Y-up, 1 unit = 1 metre, T-pose or A-pose, PBR textures.
Also fine: `.fbx`, `.blend`, `.gltf` with textures. Unrigged models are fine; they can be rigged in Blender.

If any single file is over 100 MB, tell me and we will enable Git LFS first.
