# Campaign architecture (v0.9)

Source of truth for story: `docs/sources/Kalki_Purana_Game_Reference.pdf` (missions M00-M17, tiers A/B/G, ethics rules).
Everything about a mission lives in data: `data/missions.json` (existing descriptive fields + a `play` block),
`data/dialogue.json` (lines, en/hi/te, tier + locator), `data/strings.json` (UI/objective text).
These files are generated by `tools/content/build_content.py` from the Python content modules next to it; edit the
modules, not the JSON.

## Runtime pieces
| Piece | File | Job |
|---|---|---|
| Campaign (autoload) | `scripts/campaign.gd` | mission data, progress/flags save (`user://save.cfg`), unlocking, start/complete |
| Mission host | `scripts/main.gd` | builds a mission from its `play` block, runs the objective list, win/lose |
| Objectives | `scripts/mission_runner.gd` | objective types: talk, reach, defeat, spar, rings, collect, boss, cutscene, choice, survive, codex, restore |
| Dialogue | `scripts/dialogue_box.gd` | sequential lines with speaker, tier tag, choices; tap/Enter advances |
| NPCs | `scripts/npc.gd` | rigged Rodin characters standing idle, name label, interact prompt |
| Menu | `scripts/campaign_menu.gd` | mission list (locked/done), continue, codex, language |
| Codex | `scripts/codex.gd` | lore entries with tier tags and sources |
| Player | `scripts/player.gd` | `mode` mounted (Kalki on Devadatta) or foot (rigged Kalki, sword after M04) |

## Rules
- Enemies are defined by deeds, never by identity (PDF section 10). Training constructs and spar opponents never die.
- New dialogue is `DRAMATIZED_ADAPTATION`; tier B unless noted; G for pure game additions.
- Models that have not been delivered use a clearly flagged stand-in (`"standin": true`); list in `docs/HANDOFF.md`.
- Hindi and Telugu subtitles exist for every line; only the five key lines have voice (credit budget).
